# 🐍 python-lore

A curated collection of Python fundamentals, data structures, practice programs, and mini-games documenting my Python learning journey.

---

## ✨ What's Inside

* **Core Fundamentals:** Syntax, variables, data types, operators, and I/O basics.
* **Control Flow:** Decision-making with conditionals (`if`/`elif`/`else`) and iteration (`for`/`while` loops).
* **Data Structures:** Hands-on exercises with lists, tuples, sets, and dictionaries.
* **Practice & Tutorials:** Problem-solving scripts, coding exercises, and concept walkthroughs.
* **Mini-Games:** Interactive terminal-based games built in Python.
